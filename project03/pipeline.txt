1. Preprocess each image
    - Crop each bounding box separately
    - Resize each crop to a normalized size
    - Normalize contrast / illumination
2. Segment the climbing hold
    - Compare snakes, HSV color clustering, and GrabCut
    - Produce a binary mask for the hold
3. Extract geometric features
    - Binarize using the segmentation mask
    - Use connected-component / region properties to compute shape features
    - Store these as a geometric feature vector
4. Extract appearance features
    - Run SIFT and aggregate descriptors with Bag of Visual Words
    - Concatenate appearance features with geometric features
5. Train classifier
    - Standardize the concatenated feature vectors
    - Train and evaluate a multiclass SVM
